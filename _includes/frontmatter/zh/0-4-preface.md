# 前言

《经济》是一部现代化的教材，被全球超过65个国家的高校所采用，旨在应对当下最为紧迫的经济问题，例如不平等、气候变化、金融不稳定、工作的未来，以及创新。

CORE Econ团队编写的第一版《经济》于2017年面世。《经济2.0：微观经济学》和《经济2.0：宏观经济学》重新编排了教材结构并大幅修改了相关内容，进一步优化了教学和学习体验，以回应我们从课堂上以及其他老师和学生处获得的反馈。

2014年我们首次在线发布《经济》教材的测试版本，卡米拉·塞亚（Camila Cea）为其撰写了前言。她虽然当时刚从经济学专业毕业，却已在智利多次参与抗议活动，呼吁政府推行促进经济正义的政策。她和智利大学的同学们对经济学课程的教学内容感到震惊，因为这些课程无法解决任何他们所关心的任何智利经济问题。他们要求对课程体系进行改革。时任经济与管理学院的主管奥斯卡·兰德雷切（Oscar Landerretche）相应了他们的诉求。

卡米拉·塞亚在项目初期时对CORE Econ的看法准确地捕捉到了那鞭策我们不断向前的动力。她写道：

> 我们希望改变经济学的教学方式。学生们和老师们告诉我们，这个变化早该发生了。2013年11月，《金融时报》[对CORE项目的报道](https://tinyco.re/4161856){:.show-url}在网络上引发了关于经济学教育与学习的[广泛讨论](https://tinyco.re/9857489){:.show-url}，短短48小时内便收到了1214条评论。全球各地的经济学学生都在提一个我几年前也曾提过的问题：“为什么经济学这门学科已经与我们对现实生活的感知脱节了？”
>
> 和我一样来自拉丁美洲的经济学学生娜塔莉·格里萨莱斯（Nataly Grisales）最近在她的博客中写道：“在我选择经济学专业之前，一位教授曾提到经济学将教给我使用数学工具描述和预测人类行为的方法。这种可能性至今仍让我感到惊奇。然而，在经过几个学期的学习后，我掌握了许多数学工具，但那些我原本想要研究其行为的对象却从课堂上消失了。”
>
> 和娜塔莉一样，我也曾问自己，我的经济学课程是否会真正触及那些最初促使我学习这一专业的核心问题。

卡米拉·塞亚和娜塔莉·格里萨莱斯并未从经济学课程中真正感受到经济学的独特魅力和价值。CORE Econ的使命是向学生介绍当代经济学家的研究内容和成果。如今，经济学是一门运用模型来解读数据的实证学科。这些模型为政府、企业和其他组织在制定策略过程中面临利弊权衡时提供指导。

在CORE Econ项目运行的十年间，我们在全球的课堂中进行了一项实验。在经济学入门课程的第一天，我们会问学生：“经济学家应该解决的最紧迫问题是什么？”

这些词云涵盖了多个全球性议题，例如普遍存在的不平等和环境问题。同时，不同国家的词云也存在一些差异，这表明各国也存在着一些地方性社会问题，诸如自然资源的利用。最新的词云显示，在新冠疫情大流行结束后，乌克兰战争引起的通货膨胀和生活成本危机成为又一个亟待解决的紧迫问题。

当下，经济学被公众、媒体和潜在的学生认为是一门抽象的学科，主要与赚钱有关，却与现实世界脱节。然而，纵观经济学的发展历程，在大多数时候它都致力于理解并改变世界的运作方式，而CORE Econ项目正是延续了这一传统。早期的经济学家——例如16至17世纪的重商主义者，或是法国大革命前夕的重农主义者——常为当时的统治者提供执政建议。一些学者也承担了同样的职责，例如14世纪的北非学者伊本·赫勒敦（Ibn Khaldun）。

如今，宏观经济政策制定者、为线上经济开发平台的私营部门经济学家、经济发展顾问和智库专家正携手构建一个繁荣且可持续发展的美好世界。这既是经济学最鼓舞人心的使命，也是其面临的最大挑战。

## 革新入门课程的基准框架

经济学科在完善研究工具方面取得了显著进展，这些工具将帮助我们理解、解释和应对当今面临的各项挑战。在本书中，您将接触到包括战略互动（博弈论）、有限信息、委托—代理模型、人类行为与偏好（不仅包括自利和风险规避，还包括利他主义）在内的多种工具和概念，以及创造性毁灭和不稳定性等动态变化过程。

这些工具和概念每天都被政策制定者、业界经济学家和学界经济学家广泛使用，已经成为经济学科的主流内容。这些内容在博士项目内被广泛教授，但在本科一年级教材中并不常见。可惜的是，这常常意味着许多学生在初次接触经济学时接触到的理论框架既与现实世界脱节，也与大多数经济学家实际思考问题的方式相去甚远。《经济》提供了一个新的基准框架，它既富有吸引力，又具有连贯性，因此对于本科一年级学生来说更易于理解。

## 聚集反映现实问题的真实世界数据

我们关注现实问题，这也是我们将本书命名为《经济》而非传统入门教材常用的《经济学》的原因。《经济》一书充分结合了真实数据和前沿的实证研究：

- 《经济》中的许多图表都已经链接到我们的合作伙伴[“全球数据网”](https://tinyco.re/9727320){:.show-url}（Our World in Data，简称OWiD）。您可以点击每张图表下方的按钮，以交互形式访问最新数据。
- “经济学家如何从事实中总结规律”方框将向您介绍经济学的实证方法，并展示经济学家如何运用这些方法评估政策效果是否达到预期。
- 这本教材同时也链接到了《[经济学实践](https://tinyco.re/2732207){:.show-url}》教材，您可以学习使用Excel或R语言处理真实数据，逐步掌握数据分析和可视化技巧。

## 全球承诺：合作创造开放知识

CORE Econ是一个真正意义上的全球性项目，这体现在两个方面：项目汇聚全球智慧共同研发，同时也向任何地方、任何想要使用这本教材的读者开放。

我们使用的众多板式设计和交互功能最初由印度班加罗尔团队开发完成，教材文本和在线材料的开源平台则由南非开普敦团队制作提供。数百位学者为这些材料贡献了内容，并参与了编辑和审阅工作。教材各单元的主要作者来自15个国家，他们无偿贡献了自己的专业知识和知识产权。《经济1.0》已被翻译成西班牙语、法语、芬兰语、意大利语、葡萄牙语和德语。此外，还有一个介绍南亚及发展中经济体特有主题和特色的改编版本——《经济：南亚视角》。

CORE Econ通过知识共享许可协议将所有电子书及相关资源在线开放，允许全球范围内非商业用途免费使用。我们是一个由知识生产者组成的合作组织，致力于提供免费在线访问的CORE Econ资源库，以帮助全球公民掌握经济学的语言、事实和概念，从而获得更强的认知能力。我们希望尽可能多的人能够理性思考并采取行动，携手应对21世纪经济、社会和生物圈面临的挑战。我们希望让经济学的思想精粹成为每个公民理解和解决我们当前面临问题的一剂良方。
